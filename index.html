階段判斷：以 200 日均線一個月內的方向為主軸（變動在 ±0.75% 內視為走平），搭配股價與 50、150、200 日均線的相對位置；均線走平時，回看約五個月前的方向，區分頭部（第三階段）與底部（第一階段）。「正在起漲」＝ 轉入第二階段 40 個交易日內、前一個階段是第一階段，且股價在 52 週高點 85% 以上。RS 為同市場內近一年加權報酬的百分位（1–99）。均線本身有落後性，階段轉折通常會晚幾週才反映。本頁僅為技術面篩選工具，不構成投資建議。

本機下單程式　未連線 在 Windows 執行 python -m trader.order_server（或 --dry-run 演練、--live 正式），把終端機顯示的配對碼填進來。未連線時仍可編輯與匯出計畫 JSON。

送出前會再顯示確認視窗。台股委託選項依凱基 SuperPy 2.1.2 的實際 API；API 不支援或交易所不接受的選項會停用，原因寫在每張委託下方的「為什麼有些選項不能選」。美股（複委託）只支援限價、ROD，且凱基沒有複委託模擬環境，模擬模式下由下單程式在本機模擬成交。

庫存由本機下單程式向凱基查詢（台股 InventorySum、複委託 StockPositionReport）。
請先在「下單面板」連線本機下單程式。
未連線 「全部取消」刪除本程式送出的所有未成交委託與等待中的進場單；「全部平倉」另外把本程式監控中的部位全部平倉，並停止今日新委託。都不會動到你在其他軟體下的單。
券商連線中斷，正在自動重新登入；重連前不送新委託，觸發的出場會在重連後立即送出。
